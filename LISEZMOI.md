# Mes dépenses — application Android

Les dépenses sont enregistrées sur le téléphone, sans Internet.
Attention : désinstaller l'application efface les données.

## Obtenir l'APK avec GitHub (gratuit, sans rien installer)
1. Créez un compte sur github.com, puis « New repository » (nom : MesDepenses).
2. « uploading an existing file » : glissez TOUT le contenu de ce dossier
   (y compris le dossier .github), puis « Commit changes ».
3. Onglet « Actions » : la construction démarre (3 à 5 min).
4. Quand elle est verte, ouvrez-la et téléchargez « MesDepenses-APK » (un .zip
   contenant MesDepenses.apk).
5. Sur le téléphone : ouvrez MesDepenses.apk et autorisez
   « Installer des applications inconnues » si Android le demande.

## Avec Android Studio
Ouvrir ce dossier, puis Build > Build APK(s).
